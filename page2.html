THIS IS ABOUT ME

ขอแนะนำตัวอีกครั้ง ผมชื่อ ปารเมศ ไชยเวช ชื่อเล่น ภูกล้า อยู่ชั้นมัธยมศึกษาปีที่ 5 โรงเรียนมงฟอร์ตวิทยาลัยแผนกมัธยม ที่ตั้งโรงเรียน อยู่ที่ ประเทศไทย จังหวัด เชียงใหม่ อำเภอเมืองเชียงใหม่ และ ตำบล ท่าศาลา ซึ่ง คนใน โรงเรียน ผมชอบเรียนว่า อัสสัมชัญ ท่าศาลา เพราะโรงเรียนผมชื่อแปลก แตกต่างกับชื่อโรงเรียนในเครือ


ซึ่งอนาคตผม อยากจะเข้า วิศวะคอมซึ่งเป็นจุดมุ่งหมายในชีวิต แต่ถ้าไม่ติดผมก็จะไปนั่งขุดฟอสซิวอยู่เหมือง ขอนแก่นๆ หาไดโนเสาร์ ครับ ชอบไดโนเสาร์ครับ แต่ผมไม่ชอบชีวะเลยไม่น่ารอด ตัวเลือกวิศวะคอมจึงเป็นสิ่งที่เหมาะกับผมที่สุดครับ


ผมชอบเรียนและศึกษาเนื้อหาในด้านคณิตศาสตร์และวิทยาการคอมพิวเตอร์ จึงเป็นอีกเหตุผลที่ผมอยากเข้าวิศวะคอมครับ ซึ่งพอจบไปก็อยากไปทำงานเกี่ยวกับด้าน full stack develop ครับ ซึ่งเป็นสายงานที่ต้องรู้ทุกเรื่องทั้ง frontend , backend ซึ่งเป็นโจทย์ที่น่าจะยากมากสำหรับเด็กคนนึงที่มีความรู้แค่ html , css , javascript , python , c และจึงเป็นอีกเหตุผลที่ทำให้ผมอยากเข้าวิศวะคอมครับ
